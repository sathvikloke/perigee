# Curated preset assets

Generated by `tools/ingest/build_presets.py` from the retained original SPHEREx cutouts, using
the same `backend/data` code as the live API. Do not edit by hand. Rebuild instead:

```bash
python tools/ingest/fetch_manifest.py --out ../perigee-data/raw     # re-downloads + verifies SHA-256
python tools/ingest/build_presets.py --raw ../perigee-data/raw
python tools/ingest/check_registration.py --raw ../perigee-data/raw
```

| Path | What |
|---|---|
| `manifest.json` | Index: presets, case sets and every asset (`asset_id` → `path`, `sha256`, `bytes`, `media_type`) |
| `<preset_id>/frames.json` | All retained frames for the preset, ordered by mid-exposure `mjd` then `frame_key`, one 4′ grid, per-frame contrast |
| `<preset_id>/sets/<case_id>.json` | The case's frames (`case_ref` A/B/C) exactly as listed in `backend/content/cases/<case_id>.json`. The refs in `shared_scale.refs` share one stretch; the others keep their own |
| `<preset_id>/sets/<case_id>.registration.json` | Field-star registration check for the set |
| `<preset_id>/img/*.png` | Intensity PNGs (grey + alpha) and flag overlays |

Every `image.src` / `flag_image.src` is `/api/v1/assets/<asset_id>`. Serve only IDs listed in
`manifest.json`, and never accept a path from the request. Every record has
`delivery: "curated"` at the file level, so the UI can say these frames were prepared in
advance and not fetched live.

Size: 378 PNGs, ~4.3 MB in total. No FITS files.

Contents: Barnard's Star 34 frames (all flagged at the saturated star), Epsilon Indi B 44
(29 clear, 14 flagged, 1 not covered), WISE 0855 34 (21 clear), RW Aurigae 35 (1 clear, 2 not
covered), R Draconis 36 (35 flagged, 1 not covered). These are the same counts as Sathvik's
independent check.
