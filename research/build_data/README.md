# Original SPHEREx downloads

Only Sathvik and Sagar need the full dataset. The original FITS files, archive metadata, source URLs/hashes, and official reference PDF remain local. Large downloads are excluded from Git.

- `raw/`: 183 original FITS cutouts.
- `metadata/`: archive search results and resolver responses.
- `manifest.json`: source URLs, hashes and audit metadata.
- `reference/`: explanatory supplement and its source record.

The prior processing scripts, generated previews, frontend manifest, case files and starter ZIP have been removed. Build the application and processing pipeline from scratch during the event.
