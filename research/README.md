# Research records

This folder contains observational audit results and links to original sources.

- [audit_scope.json](audit_scope.json): scope and limitations of the earlier three-source outburst audit.
- [audit_results.json](audit_results.json): earlier SPHEREx/NEOWISE inspection findings.
- [source_urls.json](source_urls.json): original source URL mapping for those files.
- [build_data/manifest.json](build_data/manifest.json): five-target source-data download ledger.
- [build_data/reference/sources.json](build_data/reference/sources.json): official technical reference source and hash.

Original FITS, CSV/XML downloads and the reference PDF remain local and are excluded from Git. Processing scripts and generated application assets have been removed. Build the new application and data pipeline during the event.

See [the data guide](../docs/DATA.md) and [the research synthesis](../docs/RESEARCH.md).
