# Discovery-first UI refinement

User-approved scope: preserve black/citron, typography and cartoon hero; make the actual sky comparison the next visual focus and move the notebook after observation.

- Landing: a full-width featured Barnard comparison uses the authored A/C products. Two smaller guided alternatives follow.
- Playback: starts paused, swaps exact original images on a fixed grid every second (1.5 seconds with reduced motion), stops offscreen/on hidden tab/print/unmount, and offers direct date selection. Dates and wavelengths remain attached to each image.
- The fixed ring uses the earlier frame’s catalog coordinate and is labeled accordingly. It is not a measured centroid. Pixel hatching and saturated-core context stay visible.
- Guided workspace: compare, review checks, then record. Free exploration keeps its established layout.
- Submission: a separate editorial pass leads with learner decisions and evidence that a teacher can inspect; no invented users or measured learning outcomes.

Verification and production identity will be recorded after rendered checks and deployment.
